# AI Agent Learning

A guided course from first principles to tested agent applications.
Complete one project at a time and explain what you built before progressing.

| Stage | Project | Learning goal |
| --- | --- | --- |
| 00 | Agent loop demonstration | Decisions, tools, observations, stopping |
| 01 | Simple AI assistant | Prompts, model calls, responses; an assistant baseline |
| 02 | Calculator agent | Model-chosen tools and argument validation |
| 03 | Study coach | Conversation history and persistent state |
| 04 | Document Q&A | Retrieval, source references, and grounding |
| 05 | CSV analyst | Data inspection, calculations, and reports |
| 06 | Incident triage | Structured workflows and human approval |
| 07 | Tested agent service | Evaluation, failures, limits, and deployment |
| 08 | Research team | Agent coordination and comparison with a single agent |

Only exercise 00 is implemented in this starter. Future projects will be added
as we work through the lessons. Model-powered projects need a provider setup;
we will choose that together before making any paid API calls.

Each completed project should include runnable code, clear setup instructions,
examples, limitations, and checks appropriate to its behavior.

Start with `00-agent-loop/README.md`.
